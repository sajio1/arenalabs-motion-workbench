# Isaac replay validation — 2026-10-19

Scope: standalone kinematic visual replay in NVIDIA Isaac Sim 5.1.0 on RTX A6000.
No PhysX articulation/controller or dynamics result is claimed.

| Case | Frames | Visual meshes | Checked world poses |
|---|---:|---:|---:|
| H2 + Wuji | 1,057 | 88 | 93,016 |
| H2 + Robotiq | 95 | 58 | 5,510 |
| Skye | 300 | 30 | 9,000 |
| Luna + Wuji | 266 | 75 | 19,950 |

All passed: every USD mesh transform at every frame was compared with the original
playback after the declared Y-up → Z-up basis change. Maximum translation error
was below 5.1e-12 m; maximum rotation-matrix element error was below 3.6e-12.
Six forward/backward/end-point timeline seeks per case were rendered in Isaac.

H2/Wuji was additionally tested after extracting the final newly exported ZIP.
All 3,529 file hashes in that complete multimodal package matched. Skye used a
saved native qpos trajectory, repackaged without rerunning the motion solver;
independent MuJoCo FK reproduced its saved body positions exactly. Skye's vendor
wheel joints are fixed: planar base motion is baked into the visual world poses,
not generated by wheel actuation. This older cached Skye sequence is not evidence
of a new six-point motion solve.

The former package contained named joint references and per-mesh global visual
poses but no standalone simulator replay entry. Named state/action arrays are
not native simulator qpos: floating-base conventions, passive joints, mixed
hinge/slide units and mounted-hand joints must not be inferred from array order.
The new CPU export always includes a self-contained USD animation, player,
explicit replay contract and validation script. Older immutable exports require
a fresh download. The USD solves portable visual playback; an external physical
robot controller still needs a matching articulated model and native DOF mapping.

Validation implementation: `dataset_io/isaac_replay.py`; contract and commands:
[dataset-io.md](dataset-io.md). Twelve dataset/replay tests passed in the cloud
runtime; no motion model, scene reconstruction or online playback policy changed.
